# SELTERN preview

## Reproduce artifacts

- This worktree contains the complete standalone Vite app; no `.env.local` file is required.
- Install dependencies with `npm install` from the project root.

## Run the server

- Start the development server with `npm run dev`.
- Vite uses its default port `5173`; if that port is unavailable, pass an alternate `--port` value and register the matching URL.
